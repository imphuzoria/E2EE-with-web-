# SecureMessenger

Защищённый мессенджер с End-to-End шифрованием (E2EE) для безопасного обмена сообщениями, файлами и голосовыми заметками. Работает через локальный сервер и поставляется в виде автономного Windows `.exe`.

## 🔐 Как устроено шифрование

- **AES-256-GCM** — аутентифицированное шифрование каждого сообщения и файла (ключ 256 бит, тег 128 бит, свежий IV 96 бит на каждое сообщение).
- **PBKDF2-HMAC-SHA256** (210 000 итераций) — вывод симметричного ключа из кодовой фразы комнаты. Соль уникальна для каждой комнаты (детерминированно выводится из `roomId`).
- **ECDH P-256** — пара ключей для проверки отпечатков собеседников (Safety Numbers, как в Signal).
- **Zero-knowledge сервер** — сервер хранит только зашифрованные блобы; ключи и открытый текст никогда не покидают браузер.

## 🚀 Быстрый старт

### Способ 1 — автономный EXE (рекомендуется для пользователей)

1. Скачайте `release/SecureMessenger.exe` (7–8 МБ, без установки, без Node/Python).
2. Запустите двойным кликом — приложение поднимет локальный сервер и откроет браузер.
3. Чтобы общаться, второй человек запускает тот же `.exe` (или открывает ваш адрес по сети) и входит в ту же комнату по коду/QR.

> Файл `.exe` можно передать собеседнику прямо из приложения: «Настройки → ПК и звук» или кнопка `SecureMessenger.exe` в шапке.

### Способ 2 — запуск из исходников (для разработчиков)

Требования: Node.js 18+, Python 3.9+.

```bat
install.bat      :: установка зависимостей (npm + pyinstaller)
start.bat        :: запуск сервера и открытие браузера
```

или вручную:

```bash
npm install
npm run dev        # режим разработки (Vite HMR)
# либо, после сборки:
python app.py      # сервер на стандартной библиотеке Python
```

Откройте http://localhost:3000

## 📦 Сборка автономного EXE

```bat
build.bat
```

Это выполнит:
1. `npm run build` — сборка React-frontend в `dist/`.
2. `python build_windows.py` — упаковка `app.py` + `dist/` в единый `release/SecureMessenger.exe` (PyInstaller, onefile, noconsole).

## 🔧 Использование

### Создание защищённой комнаты
- **Ctrl+K** или «+» в сайдбаре → задайте ID комнаты и секретный ключ (или сгенерируйте).
- Поделитесь приглашением: QR-код, ссылка или код.

### Присоединение
- Вкладка «Войти по коду» в окне приглашения, либо прямая ссылка:
  `http://localhost:3000#room=ROOM_ID&key=PASSPHRASE`

### Отправка
- **Текст** — Enter.
- **Файлы** — 📎 (до 50 МБ) или перетащите файл в окно.
- **Голосовые** — 🎤.

### Экстренное стирание
- **Ctrl+Shift+P** — очистка ключей, истории и локального хранилища.

## 🛡️ Безопасность (исправленные уязвимости)

- ✅ **Rate limiting** на всех API-эндпоинтах (защита от спама/DDoS).
- ✅ **Валидация `roomId`/`fileId`** — блокирует path traversal и инъекции.
- ✅ **Лимит 50 МБ** на файлы и буфер комнаты (защита памяти).
- ✅ **Защищённые HTTP-заголовки**: `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, `CSP`.
- ✅ **Уникальная соль PBKDF2 на комнату** (было — жёстко зашитая соль).
- ✅ **210 000 итераций KDF** (было 100 000).
- ✅ **Криптографический генератор** ID и паролей вместо `Math.random()`.
- ✅ **Исправлена расшифровка имён файлов** (IV файла раньше терялся).
- ✅ **Кэш ключей на комнату** (не пересчитываем PBKDF2 на каждое сообщение).
- ✅ **Комнаты переживают перезагрузку страницы** (persistence).

### Ограничения (важно знать)

- Хранилище — **в памяти**: при перезапуске сервера история очищается.
- Сервер видит **метаданные** (кто/когда/размер файла), но не содержимое.
- Для сети (не localhost) нужен **HTTPS**, иначе браузер блокирует Web Crypto.

## 📡 API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/health` | статус |
| GET | `/api/rooms/:roomId/events` | SSE-поток событий комнаты |
| POST | `/api/rooms/:roomId/messages` | зашифрованное сообщение |
| POST | `/api/rooms/:roomId/files` | зашифрованный файл |
| GET | `/api/rooms/:roomId/files/:fileId` | скачивание файла |
| POST | `/api/rooms/:roomId/typing` | индикатор набора |
| DELETE | `/api/rooms/:roomId/messages` | очистка комнаты |
| GET | `/api/download-exe` | скачать сам `.exe` |
