# Настройка автономного локального запуска на http://localhost:3000 через .bat / .exe

План обновления лаунчера: перенаправление запуска на локальный сервер ПК (`http://localhost:3000`), автоматический запуск фонового Node.js сервера и открытие браузера на локальном адресе без использования внешних облачных ссылок.

> [!IMPORTANT] Подтвержденный выбор пользователя:
> Лаунчер `.bat` / `.exe` на ПК должен запускать и открывать **локальный сервер на ПК `http://localhost:3000`**, а не облачный URL.

---

### Что такое адрес `ais-dev-...europe-west3.run.app`?
Этот адрес — временный облачный URL веб-хостинга для интерактивной разработки и тестирования проекта в облаке. 
Ранее лаунчер по умолчанию копировал текущий URL из адресной строки браузера. Теперь он будет полностью переведён на автономную работу с вашим локальным компьютером: `http://localhost:3000`.

---

### 1. Архитектура локального запуска на ПК

При нажатии на `####.exe` или `####-launcher.bat` на вашем компьютере:
1. Запускается локальный сервер Node/Express на порту `3000`.
2. Автоматически открывается браузер по адресу `http://localhost:3000`.
3. Все данные, шифрование и ретрансляция происходят локально на вашем ПК (Zero-Knowledge localhost).

```
┌────────────────────────────────────────────────────────┐
│                   ВАШ КОМПЬЮТЕР (ПК)                   │
│                                                        │
│   [####-launcher.bat / ####.exe]                       │
│          │                                             │
│          ├──► 1. Запуск сервера: node server.ts        │
│          │       (Локальный порт 3000)                 │
│          │                                             │
│          └──► 2. Открытие браузера:                    │
│                  start http://localhost:3000           │
│                                                        │
│   [Графическая оболочка в браузере localhost:3000]     │
└────────────────────────────────────────────────────────┘
```

---

### 2. Изменения в приложении

1. **Обновление скрипта лаунчера `####-launcher.bat` в `ExeLauncherModal`**:
   - Автоматическая проверка и запуск локального сервера:
     ```bat
     @echo off
     title #### - Local Server & UI
     echo [####] Запуск локального сервера на http://localhost:3000...
     start http://localhost:3000
     call npm run dev
     ```
2. **Кнопка скачивания локального пакета**:
   - Возможность скачать готовый zip-архив с проектом для моментального запуска на любом ПК с Node.js.
3. **Обновление инструкций создания `.exe`**:
   - Добавление инструкции по упаковке в один клик через `iexpress` или утилиту `pkg` для сборки единого `.exe` без консольного окна.

---

### 3. Шаги реализации (после одобрения плана)

1. Обновить `src/components/ExeLauncherModal.tsx`:
   - Встроить локальный скрипт запуска `http://localhost:3000`.
   - Добавить пояснение об адресах (локальный `localhost:3000` vs веб-версия).
2. Проверить сборку через `lint_applet` и `compile_applet`.
